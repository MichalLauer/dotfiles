# Init

```bash
cd ~
git clone git@github.com:MichalLauer/dotfiles.git
```

# Git (>= v2.36)

## MacOS

```bash
ln -s ~/dotfiles/git/.gitconfig ~/.gitconfig

```

# Shell

## Windows

```bash
ln -s ~/dotfiles/shell/.bashrc ~/.bashrc
```

# MacOS

```bash
ln -s ~/dotfiles/shell/.bashrc ~/.bashrc
ln -s ~/dotfiles/shell/.zshrc ~/.zshrc
```
